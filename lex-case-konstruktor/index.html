    О проекте

    LEX CASE разработан с использованием ИИ-агента. ИИ применялся для проектирования структуры приложения, программирования интерфейса и логики, подготовки и проверки учебных сценариев.

    Приложение работает автономно: не требует регистрации, API-ключей, сервера или установки библиотек и не передаёт введённые пользователем данные сторонним сервисам.
